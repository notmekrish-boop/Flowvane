## Platform

## Users

Student project teams and small teams that need to coordinate shared work. This audience is based on the user's confirmation and the current product capabilities.

## Product Purpose

TaskPilot AI (shown in the current interface as Flowvane) helps teams plan projects, assign and track tasks, coordinate in workspaces, and keep project knowledge in notes and diagrams. AI assistance supports planning and project understanding. This summary is inferred from the existing application and project specification.

## Capabilities and Constraints

- Project and task management, team membership, workspace switching, workspace chat, direct messages, notifications, notes, diagrams, and AI assistance are present in the application.
- The interface must preserve existing product workflows and data while its visual design changes.
- The confirmed visual direction is a compact project dashboard inspired by the first supplied reference, pixel-art icons, a collapsible navigation rail, and a true-black/dark palette with yellow or amber accents inspired by the second reference.
- Product positioning, supported team sizes, and AI provider guarantees are not established here.

## Brand Commitments

- The repository/project is named TaskPilot AI; the existing product interface uses the name Flowvane. Preserve the current Flowvane interface name unless the user changes it.
- The user supplied two visual references as binding design direction: a compact card-based project dashboard and a black interface with yellow/orange accents.

## Evidence on Hand

- Existing application routes and implemented workflows in `frontend/src/App.jsx` and related pages.
- User-provided dashboard and dark-theme screenshots in the conversation. These are references for layout and palette only; do not reuse their brand names, data, or assets.

## Product Principles

- Make project status and next actions easy to scan.
- Keep shared work and personal work clearly associated with the active workspace.
- Preserve existing records and workflows when improving the interface.
- Use AI as an aid to project work, with clear context boundaries.
